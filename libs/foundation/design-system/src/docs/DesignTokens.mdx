# Design Tokens

Design tokens are the visual design atoms of the design system — the smallest pieces of style that are used to build components. They represent design decisions like colors, spacing, typography, and more.

## Overview

Our design tokens are implemented as CSS custom properties using Tailwind CSS 4's `@theme` directive. This provides several benefits:

- **Single Source of Truth** — Tokens are defined once and used everywhere
- **Runtime Theming** — Themes can be changed dynamically without rebuilding
- **Tailwind Integration** — Tokens automatically become Tailwind utilities
- **Type Safety** — TypeScript definitions for programmatic access

## Using Tokens

### In CSS/SCSS

```css
.my-component {
  background-color: var(--color-primary);
  padding: var(--spacing-4);
  border-radius: var(--radius-md);
}
```

### In Tailwind Classes

```tsx
<div className="bg-primary p-4 rounded-md">Content</div>
```

### In JavaScript/TypeScript

```tsx
import { tokenValues } from '@open-zentra/foundation-design-system';

const primaryColor = tokenValues.colorPrimary; // '#2563eb'
```

## Color Tokens

### Primitive Colors

Primitive colors are the raw color palette. These should generally not be used directly in components — use semantic colors instead.

#### Blue Palette

| Token              | Value     | Usage           |
| ------------------ | --------- | --------------- |
| `--color-blue-50`  | `#eff6ff` | Lightest blue   |
| `--color-blue-100` | `#dbeafe` | Very light blue |
| `--color-blue-500` | `#3b82f6` | Mid blue        |
| `--color-blue-600` | `#2563eb` | Primary blue    |
| `--color-blue-900` | `#1e3a8a` | Darkest blue    |

#### Gray Palette

| Token              | Value     | Usage             |
| ------------------ | --------- | ----------------- |
| `--color-gray-50`  | `#f9fafb` | Background subtle |
| `--color-gray-100` | `#f3f4f6` | Background muted  |
| `--color-gray-500` | `#6b7280` | Muted text        |
| `--color-gray-900` | `#111827` | Primary text      |

### Semantic Colors

Semantic colors communicate intent and should be used in components.

#### Primary

| Token                        | Value                   | Usage                |
| ---------------------------- | ----------------------- | -------------------- |

| `--color-primary-active`     | `var(--color-blue-800)` | Active/pressed state |

## Dark Mode

The design system includes automatic dark mode support through the `prefers-color-scheme` media query. Semantic tokens are automatically adjusted for dark backgrounds.

Key changes in dark mode:

- Background colors become dark grays
- Foreground colors become light grays
- Primary/accent colors remain consistent for brand recognition
- Border colors are adjusted for contrast
