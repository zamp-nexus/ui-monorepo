# Open Insights Design System

Welcome to the Open Insights Design System — an enterprise-grade React component library built for consistency, accessibility, and developer experience.

## Overview

The Foundation Design System provides a comprehensive set of reusable UI components, design tokens, and utilities that power the Open Insights platform. It's designed to help teams build consistent, accessible, and beautiful user interfaces efficiently.

### Key Features

- **30+ Production-Ready Components** — From buttons to complex modals, all components are thoroughly tested and accessible
- **Design Tokens** — A complete token system using CSS custom properties with Tailwind CSS 4 integration
- **Accessibility First** — WCAG 2.1 AA compliant with built-in keyboard navigation and screen reader support
- **TypeScript Native** — Full type safety with comprehensive TypeScript definitions
- **Themeable** — Customizable themes with light/dark mode support out of the box
- **Enterprise Ready** — Built with scalability, maintainability, and performance in mind

## Installation

The design system is available as an internal package within the monorepo:

```tsx
import { Button, Input, Modal } from '@open-insights-web/foundation-design-system';
```

## Quick Start

Here's a simple example to get you started:

```tsx
import { Button, ThemeProvider, defaultTheme } from '@open-insights-web/foundation-design-system';

function App() {
  return (
    <ThemeProvider theme={defaultTheme}>
      <Button intent="primary" onClick={() => console.log('Clicked!')}>
        Get Started
      </Button>
    </ThemeProvider>
  );
}
```

## Component Categories

### Form Controls
- **Button** — Primary action triggers with multiple variants
- **Input** — Text input fields with validation states
- **Checkbox** — Boolean selection controls
- **Radio Group** — Single selection from multiple options
- **Select** — Dropdown selection menus
- **Switch** — Toggle switches for binary settings
- **Textarea** — Multi-line text input

### Feedback & Status
- **Alert** — Contextual feedback messages
- **Banner** — Page-level notifications
- **Toast** — Temporary notification messages
- **Progress** — Progress indicators
- **Spinner** — Loading spinners
- **Skeleton** — Content loading placeholders

### Overlays
- **Modal** — Dialog windows for focused interactions
- **Drawer** — Slide-out panels
- **Popover** — Contextual floating content
- **Tooltip** — Informational hover hints
- **Menu** — Dropdown action menus

### Layout & Navigation
- **Tabs** — Tabbed content navigation
- **Accordion** — Expandable content sections
- **Scroll Area** — Custom scrollable regions
- **Separator** — Visual dividers

### Data Display
- **Avatar** — User profile images
- **Badge** — Status indicators and counts
- **Chip** — Compact interactive elements
- **Tag** — Labeling and categorization
- **Empty State** — Placeholder for empty content

## Architecture

The design system follows a modular architecture:

```
design-system/
├── src/
│   ├── components/     # React components
│   ├── primitives/     # Low-level building blocks
│   ├── theme/          # Theme system and providers
│   ├── tokens/         # Design tokens (CSS)
│   ├── utils/          # Utility functions
│   └── types/          # TypeScript definitions
```
